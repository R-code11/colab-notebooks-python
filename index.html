About

This repository contains the complete set of materials for the Python session series conducted by the Quant Society Club at Azim Premji University, Bhopal. Each session is accompanied by a notebook designed for Google Colab, allowing students to run and experiment with code without any local setup.

The material is intended for club members and is updated after each session. All notebooks, datasets, and practice problems are hosted openly in this repository.
