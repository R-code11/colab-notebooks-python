## Overview

This problem set is designed to accompany **Session 1: Python Without Fear**. It provides a structured set of practice problems covering variables, data types, arithmetic operations, comparison operators, user input, and type conversion.

The problems are designed to be solved progressively — starting with direct application of concepts and building up to multi-concept challenges. Attempting all problems is strongly recommended before moving on to Session 2.

---

## Topics Covered

- Variables and assignment
- Integers, floats, strings, and booleans
- Arithmetic operators
- Comparison operators
- The difference between `=` and `==`
- Reading user input with `input()`
- Type conversion (`int()`, `float()`, `str()`)
- Basic string formatting in output

## How to Use This Problem Set

1. **Open the question paper (PDF)** and read all problems carefully.
2. Attempt each problem on your own in Google Colab or any Python environment.
3. Once you have attempted a problem, open the **Solutions (HTML)** to compare your approach.
4. Pay attention to the **reasoning** provided with each solution — it explains *why* the code works, not just *what* the code is.
5. If a problem uses a concept you don't remember, revisit the relevant section of the Session 1 notebook.
