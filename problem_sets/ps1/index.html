Q1

🍔 Smart Q Discount Bill

Ask student name, order amount, and loyalty points. If amount > 200 and points > 50 → 20% discount. Else if amount > 100 → 10% discount. Else no discount. Print final amount.
💻 Answer Code PYTHON 
name = input("Enter student name: ")
amount = float(input("Enter order amount: "))
points = int(input("Enter Smart Q loyalty points: "))

if amount > 200 and points > 50:
    discount = amount * 0.20
elif amount > 100:
    discount = amount * 0.10
else:
    discount = 0

final_amount = amount - discount
print("Student:", name)
print("Original amount:", amount)
print("Discount:", discount)
print("Final amount:", final_amount)

🧠 Simple reasoning:

  • We take input using input() and convert amount to float, points to int.
  • The if condition checks both amount and points using and.
  • elif checks the next condition only if the first is false.
  • else runs when no discount applies.
  • Finally we subtract discount from amount and print everything clearly.
Q2

🥗 Affordable Cafeteria Menu

Menu: ["Samosa", "Poha", "Maggi", "Tea", "Cold Coffee"]
Prices: [20, 30, 60, 15, 80]
Use for with range and if to print items under ₹50 and count them.
💻 Answer Code PYTHON 
menu = ["Samosa", "Poha", "Maggi", "Tea", "Cold Coffee"]
prices = [20, 30, 60, 15, 80]

count = 0
for i in range(len(menu)):
    if prices[i] < 50:
        print(menu[i], "-", prices[i])
        count = count + 1

print("Affordable items:", count)

🧠 Simple reasoning:

  • range(len(menu)) gives index numbers 0,1,2,3,4.
  • We use that index to get both item name and price.
  • Inside the loop, if prices[i] < 50 checks affordability.
  • If yes, we print the item and increase count by 1.
  • After the loop, we print the total count.
Q3

⏰ AI Assignment Deadline Checker

Ask submission hour and minute. Deadline is 18:00. If time invalid → Invalid time. If before or at 18:00 → on time. Else Late submission.
💻 Answer Code PYTHON 
hour = int(input("Enter submission hour (0-23): "))
minute = int(input("Enter submission minute (0-59): "))

if hour < 0 or hour > 23 or minute < 0 or minute > 59:
    print("Invalid time")
elif hour < 18 or (hour == 18 and minute == 0):
    print("AI assignment submitted on time")
else:
    print("Late submission")

🧠 Simple reasoning:

  • Check if hour is between 0–23 and minute between 0–59. If not, invalid.
  • hour < 18 means before 6 PM. hour == 18 and minute == 0 means exactly 6:00 PM.
  • If neither is true, it must be after 6 PM, so late.
  • Using or and and helps combine conditions correctly.

Q7

🚀 Smart Q Delivery Speed

Distances: [1.2, 0.8, 2.5] km, Times: [5, 4, 10] min. Calculate speed in km/h. If speed > 15 → Fast delivery.
💻 Answer Code PYTHON 
distances = [1.2, 0.8, 2.5]
times = [5, 4, 10]

for i in range(len(distances)):
    speed = distances[i] / (times[i] / 60)
    print("Speed:", speed, "km/h")

    if speed > 15:
        print("Fast delivery")

🧠 Simple reasoning:

  • Speed = distance / time. Convert minutes to hours by dividing by 60.
  • Loop through both lists using the same index i.
  • After calculating speed, check if it’s greater than 15.
  • If yes, print the fast delivery message.

🎟️ Range Token Queue

Use range to print tokens 101 to 110. Skip 105. Then print only even tokens from the same range, also skipping 105.
💻 Answer Code PYTHON 
# Skip 105
for token in range(101, 111):
    if token != 105:
        print("Token", token)

# Even tokens, also skipping 105
for token in range(101, 111):
    if token != 105 and token % 2 == 0:
        print("Even token", token)

🧠 Simple reasoning:

  • range(101, 111) gives 101 to 110 (111 not included).
  • token != 105 skips 105.
  • token % 2 == 0 checks if the number is even.
  • Combining both with and gives even tokens except 105.

📝 Filter AI Assignment Submissions

List: ["submitted", "late", "submitted", "missing", "submitted", "late"]
Count submitted, late, and missing using for and if-elif-else.
💻 Answer Code PYTHON 
statuses = ["submitted", "late", "submitted", "missing", "submitted", "late"]

submitted = 0
late = 0
missing = 0

for s in statuses:
    if s == "submitted":
        submitted = submitted + 1
    elif s == "late":
        late = late + 1
    else:
        missing = missing + 1

print("Submitted:", submitted)
print("Late:", late)
print("Missing:", missing)

🧠 Simple reasoning:

  • Start three counters at 0.
  • Loop through each status in the list.
  • Use if-elif-else to decide which counter to increase.
  • Finally print all three counts.
  • This is a simple filtering technique.

Q14

🧩 Boolean Confusion

Given A = True, B = False, C = True. Evaluate and print:
1. not A and B or C
2. A or B and not C
3. (A and B) or (not B and C)
💻 Answer Code PYTHON 
A = True
B = False
C = True

print(not A and B or C)           # True
print(A or B and not C)           # True
print((A and B) or (not B and C)) # True

🧠 Simple reasoning:

  • not works first, then and, then or (unless brackets).
  • 1: not A = False. False and B = False. False or C = True.
  • 2: B and not C = False. A or False = True.
  • 3: A and B = False. not B and C = True. False or True = True.

🛒 Smart Q Order Validator

Menu: ["Poha", "Samosa", "Maggi", "Tea"]. Ask item and quantity. If item in menu and quantity > 0 → Order accepted. Else Invalid order. Use a for loop to check item (not direct in).
💻 Answer Code PYTHON 
menu = ["Poha", "Samosa", "Maggi", "Tea"]

item = input("Enter item: ")
qty = int(input("Enter quantity: "))

found = False
for m in menu:
    if m == item:
        found = True

if found and qty > 0:
    print("Order accepted for", qty, item)
else:
    print("Invalid order")

🧠 Simple reasoning:

  • We set found = False before the loop.
  • Loop through each menu item. If it matches input, set found = True.
  • After loop, check if found is True and quantity is more than 0.
  • If both true, accept order. Otherwise, invalid.
