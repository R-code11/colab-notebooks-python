## Overview

This session introduces Python programming from first principles. No prior
programming experience is assumed. The session covers the fundamentals of
writing and executing Python code, storing values in variables, working with
numbers and text, and building a simple interactive program.

The session is conducted as part of the Quant Society Club's Python series
at Azim Premji University, Bhopal.

---

## Learning Objectives

Upon completion of this session, participants should be able to:

- Execute Python code in Google Colab
- Declare and use variables to store values
- Distinguish between integers, floats, strings, and booleans
- Perform basic arithmetic operations
- Compare values using relational operators
- Accept user input and convert it to appropriate data types
- Construct a simple marks calculator program

---

## Session Outline

1. Introduction to Python
2. Writing and running code in Google Colab
3. Comments in Python
4. Variables and assignment
5. Reassigning variable values
6. Naming rules and case sensitivity
7. Numeric types: int and float
8. Strings and text data
9. Boolean values
10. Arithmetic operators
11. Worked example: Marks calculator
12. Comparison operators
13. Difference between `=` and `==`
14. Reading user input with `input()`
15. Type conversion of input
16. Interactive marks calculator
17. Practice problems

## Practice Problems

The final section of the notebook contains practice problems divided into
three levels.

Beginner (Q1 to Q4)
Fundamentals of variables, assignment, and arithmetic.

Intermediate (Q5 to Q8)
Applied problems involving input, calculations, and output formatting.

Challenge (Q9 to Q10)
Extended problems requiring multiple concepts from the session.

Participants are encouraged to attempt each problem independently before
referring to any solution.
