## Key Concepts

Conditional statements
The `if`, `elif`, and `else` keywords allow a program to choose between
different paths of execution based on whether a condition evaluates to
`True` or `False`.

Logical operators
The operators `and`, `or`, and `not` allow multiple conditions to be
combined into a single expression.

The `for` loop
A `for` loop is used to iterate over a sequence such as a list or a range
of numbers, executing a block of code once for each item.

The `range()` function
The `range()` function generates a sequence of numbers and is commonly
used with `for` loops. It accepts a start value, a stop value, and an
optional step value.
