## Overview

This session introduces participants to the practical side of working with real data in Python. Until now, all programs dealt with values typed manually. In this session, we move to loading data from external files (CSV), inspecting it, cleaning it, and preparing it for analysis.

The session also introduces the basic workflow of data preparation — reading, understanding, and organising data — that forms the foundation for all future data analysis work.

The session is conducted as part of the Quant Society Club's Python series at Azim Premji University, Bhopal.

## Learning Objectives

Upon completion of this session, participants should be able to:

- Understand what a CSV file is and why it is widely used
- Load a CSV file into Python
- Inspect the structure of a dataset (rows, columns, data types)
- Identify missing or inconsistent data
- Perform basic cleaning and preparation steps
- Save a prepared dataset back to a file for future use
- Understand the workflow of a typical data analysis project
