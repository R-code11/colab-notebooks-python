## Overview

This session introduces **Exploratory Data Analysis (EDA)** — the process of
understanding a dataset before applying any advanced analysis or modeling.

We will work with real datasets and learn how to summarize, visualize, and
question data. By the end, you will be able to look at any unfamiliar dataset
and quickly identify its structure, issues, and key patterns.

---

## Learning Objectives

Upon completion of this session, participants should be able to:

- Understand what EDA is and why it is the first step in any data project
- Load a dataset and inspect its shape, columns, and data types
- Identify missing values and understand how to handle them
- Compute summary statistics (mean, median, min, max, std, quartiles)
- Detect outliers using simple visual and statistical methods
- Explore distributions of variables
- Examine relationships between two or more variables
- Build a first-pass understanding of a dataset through visualization

---

## Session Outline

1. Recap of Sessions 1–4
2. What is EDA and why does it matter?
3. Loading and inspecting a dataset (`shape`, `head`, `info`, `describe`)
4. Handling missing values (detect, count, decide)
5. Summary statistics: mean, median, mode, std, quartiles
6. Distributions: histograms and box plots
7. Outliers: IQR method and visual detection
8. Relationships: scatter plots and correlation
9. Categorical variables: counts and bar charts
10. Putting it together: a complete EDA checklist
11. Hands-on practice on a real dataset
